A comprehensive JavaScript learning course covering fundamentals to advanced concepts, with practical exercises and examples.

## Project Description

This repository contains a structured JavaScript learning path organized by topics and difficulty levels. It includes lessons and practical examples spanning from basic JavaScript concepts to advanced topics like async/await, classes, and destructuring.

## Project Structure

The project is organized into daily modules:

- **day1-day9**: JavaScript fundamentals (comments, data types, operators, conditions, loops, functions)
- **day10-day12**: Array methods and manipulation
- **day13**: String methods and immutability
- **day14**: Objects and object-oriented programming
- **day15-day17**: Asynchronous JavaScript (callbacks, promises, async/await)
- **day18**: Classes and object-oriented design
- **day19**: Type conversions and debugging
- **day20**: Advanced topics (destructuring, spread/rest operators, template literals, etc.)

## Prerequisites

- Node.js (v14 or higher recommended)
- npm (comes with Node.js)
- Basic understanding of programming concepts

## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/pavanoltraining/playwright_8_may_batch.git
   cd playwright_8_may_batch
   ```

2. **Install dependencies**
   ```bash
   npm install
   ```

## Usage

### Running JavaScript Files

Execute any JavaScript file using Node.js:

```bash
node day1/01_first.js
node day10/01_creating_arrays.js
node day18/01_class_example.js
```

### For Interactive Input

Some files use `prompt-sync` for user input. Make sure to follow the console prompts when running files that require interaction.

## Key Topics Covered

### Fundamentals
- Variables and scoping (let, const, var)
- Data types and type conversion
- Operators (arithmetic, logical, ternary)
- Control flow (if/else, switch statements)
- Loops (for, while, do-while)

### Intermediate
- Functions (named, arrow, anonymous)
- Arrays and array methods
- String manipulation and methods
- Objects and nested objects
- Callback functions

### Advanced
- Asynchronous programming (callbacks, promises)
- Async/await patterns
- ES6+ features (classes, destructuring, spread/rest operators)
- Template literals
- Set and Map data structures
- Date and Math methods

## Notes

- Each day's folder contains multiple exercises on the same topic
- `doubt.js` or `doubts.js` files contain clarification and edge cases
- `practice.js` files contain practice exercises
- The project uses ES6 modules (type: "module" in package.json)

## Getting Started

1. Navigate to the desired day folder
2. Open the file in your code editor
3. Read through the comments and code
4. Run the file with `node filename.js`
5. Modify and experiment with the code
